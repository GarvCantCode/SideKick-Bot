# SideKick-Bot
A discord utility bot, that can perform multiple commands without being to installed everywhere. (In future more commands would be added) 

## Requirements
- Python 3.11
- Discord Application, Bot Token & Owner User ID

## Setup
1. Clone the repo
2. Create and activate a venv
3. `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` (your own file) and fill the contents

## Troubleshooting
